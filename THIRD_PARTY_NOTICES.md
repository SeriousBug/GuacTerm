## iTerm2-Color-Schemes

**Vendored:** the color scheme definitions from the `schemes/` directory of
[iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes) — 891
`*.itermcolors` property lists — converted into the single data file
`Resources/Themes.json` so GuacTerm can offer the whole collection in
Settings › Appearance. Only the color values are vendored, never code, and the
file is regenerated from a pinned upstream commit with `make themes` (the pin
and the fetch live in `scripts/themes.sh`); `make themes-check` fails when the
checked-in file has drifted from that commit.

- Upstream: <https://github.com/mbadolato/iTerm2-Color-Schemes>
- Upstream commit behind the checked-in `Resources/Themes.json`:
  `28ae946da150fd1b3d76f5d5f48a990c357c0256`
- Vendored: `schemes/*.itermcolors` → `Resources/Themes.json`
- Not a git submodule: the collection is ~230 MB of git objects and ~34k files
  in 40 output formats, of which GuacTerm uses 891 files in one. A shallow,
  sparse fetch of the single pinned commit (`scripts/themes.sh`, into the
  gitignored `build/`) pins the same commit without making every clone pay for
  it, and keeps regeneration a reviewed change to one diffable file.

**Scheme authorship.** The scheme names are the work of their respective
authors and each scheme's copyright stays with the person who created it. The
per-scheme credits are recorded in that project's
[CREDITS.md](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/master/CREDITS.md),
which remains the authoritative list; it is not duplicated here.

## Sparkle

**Linked and bundled:** [Sparkle](https://github.com/sparkle-project/Sparkle),
which downloads and installs GuacTerm's own updates. It is a Swift package
dependency declared in `project.yml`; the framework package manager resolves is
copied into `GuacTerm.app/Contents/Frameworks` at build time, re-signed with the
app's own identity, and not vendored into this repository.

Updates are read from `appcast.xml` on the newest GitHub release (`SUFeedURL`)
and are only installed when they are signed with GuacTerm's EdDSA key
(`SUPublicEDKey`); the private half of that key is not part of this repository.
